# Context Configuration

Update Mode: ask

Detail Level: standard

Scope: project + domains

Template: generic (custom Python framework + React)

## Meaning

- **Update Mode `ask`** — when a Level 2–3 change is detected, report what
  changed, which context files are affected, and why it matters; wait for
  approval before editing context. Level 0 changes are ignored.
- **Detail Level `standard`** — capture architecture, conventions, database and
  API concepts, workflows, integrations and domains. No class/endpoint/column
  inventories, no framework tutorials.
- **Scope `project + domains`** — project-wide knowledge plus the meaningful
  domains listed in `structure.md`.
- **Template `generic`** — no framework template matched this custom stack, so
  the structure follows the actual project.
